# Sources

The research behind the requirements: one file per survey of prior art, industry practice or
literature, written while [requirements.md](../requirements.md) was being drafted. A requirement
drawn from one cites it in its provenance tag, as `_(from: sources/<name>)_`, naming the file
without its extension.

**What a file holds.** What was surveyed and when; each finding a requirement might rest on, stated
plainly; and for each, whether it was checked against a primary source (documentation, code, a
paper, a measurement) or came from the model's own knowledge. The second kind can be stale or wrong,
and a requirement resting on it is only as good as the check nobody made.

**These files are a record, not a ledger.** They are written once and not kept current: they say
what was believed when the requirements were drafted, which is what someone asking "where did this
come from?" needs to know. A finding later shown wrong is corrected with a dated note beside it, not
rewritten, and the requirements resting on it are re-examined.
